# Research and provenance

- [GalaxyBudsClient](https://github.com/timschneeb/GalaxyBudsClient):
  upstream protocol reference; its license applies to upstream code.
- [PR #729](https://github.com/timschneeb/GalaxyBudsClient/pull/729):
  experimental MDE_VERSION technique, version-only frame, volatile peer state,
  last-notification readback. Published hardware scope is Buds2 Pro/macOS.
- GalaxyBridge local evidence: Buds4 Pro/Linux controlled coexistence and noise
  commands. Reliable automatic case-cycle dual reconnect remains unresolved.

The repository contains original Python integration code; no upstream application
or firmware binaries are bundled. Preserve attribution and review upstream
licensing before importing source code in future contributions.
